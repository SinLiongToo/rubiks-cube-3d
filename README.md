一個專為魔術方塊新手與進階玩家打造的全功能互動式 Web 應用程式。融合**教學 (Learn)**、**暢玩 (Play)**、**創作與求解 (Create & Solve)** 三大核心維度，並針對新手常見痛點進行深度優化！

## 🚀 最新升級重點 (新手友善優化)

### 1. ⏱️ 慢速轉動與即時轉速調節
- **預設放慢轉速**：轉動速度大幅放慢（預設 600ms/步），且每步之間加入間隔停頓，徹底告別走馬看花。
- **頂部快速切換**：
  - 🐢 **超慢速 (1000ms)**：適合初學者逐格看清方塊軌跡。
  - 🚶 **慢速 (600ms)**：教學演練最佳速度。
  - ⚡ **正常 (350ms)**：流暢自然。
  - 🚀 **快速 (150ms)**：速解演算法體驗。
  - **細緻滑桿**：支援 100ms ~ 1500ms 任意微調。

### 2. 💡 名詞大白話圖解（什麼是黃心白花？）
在「教學學院」頂部新增**【新手必看：結構與名詞大白話】**：
- **為什麼叫「黃心白花」？**
  - **中心塊絕對固定**：黃色中心永遠在白色中心對面！
  - **新手的常見陷阱**：新手若直接在白色底面做十字，常會把邊塊側面的顏色接錯。
  - **大白話解法**：先把 4 個白色邊塊集中到頂層「黃色中心」周圍，形狀就像一朵**黃色花蕊、白色花瓣的雛菊 (Daisy)**！接著轉動頂層，讓每片花瓣側面的顏色跟側面中心顏色連成一線，再連轉 180°（轉兩次）翻到底部，底層的白色十字就 100% 完美復原，且側邊顏色保證完全正確！
- **中心塊、邊塊、角塊物理特性**：
  - 🎯 **中心塊 (6 個)**：只有 1 個顏色，轉軸固定，決定了整面顏色。
  - ➖ **邊塊 (12 個)**：十字位置，有 2 個顏色。
  - 📐 **角塊 (8 個)**：尖角位置，有 3 個顏色。
- **右手公式 (Sexy Move)**：`R U R' U'` 肌肉記憶「上、左、下、右」。
- **小魚公式 (Sune)**：頂層黃色做完十字後，只剩 1 個角塊朝上時形狀像金魚 🐟，魚頭朝左下角即可一鍵翻面！
- **車燈 (Headlights)**：頂層同側兩個角塊同色，像汽車大燈 👀。

### 3. 🧭 相對位置與文字精準對齊
- **3D 方位指南針 (Orientation Compass)**：
  - 3D 視窗左上角隨時顯示持塊指南：
    - ⬆️ 頂(U): ⚪ 白色
    - ⬇️ 底(D): 🟡 黃色
    - 👁️ 前(F): 🟢 綠色（正對自己）
    - 🔙 後(B): 🔵 藍色
    - ⬅️ 左(L): 🟠 橘色
    - ➡️ 右(R): 🔴 紅色
- **🎯 視角歸位 (Reset View)**：
  - 視窗右上角隨時可一鍵點擊「視角歸位」，旋轉視角後立即回到標準觀看角度，不再迷失方向！
- **圖文結構化對齊**：
  - 每個步驟均標明：
    - 🎯 **【此步驟目標】**
    - 🧭 **【手持姿勢】** (明確指示哪面朝上、哪面朝自己)
    - 💡 **【白話原理】**
    - 🧩 **【核心公式與口訣】**

### 4. 👣 互動單步演練器 (Step-by-Step Trainer)
- 每條公式均拆解為動作膠囊（如 `[ F ]  [ R ]  [ U ]  [ R' ]  [ U' ]  [ F' ]`）。
- **單步下一步 ▶**：一次只轉一個動作，並即時高亮顯示中文動作說明（例如：「第 3/6 步：U ➔ 頂層向左撥 90°」）。
- **◀ 單步退回**：隨時撤回上一個動作，方便反覆觀察。
- **▶ 自動連續播放**：以設定的速度平穩演示全套公式。
- **↺ 重新演練**：隨時重置並重新開始練習。
